# СКТО | Умный секундомер

Автономное PWA Союза конькобежцев Тульской области. Без сборки, без сервера: обычные HTML/CSS/JS.

## Структура
| Файл | Назначение |
|---|---|
| index.html, css/style.css | интерфейс и дизайн (тёмная и светлая темы) |
| js/timer.js | единый механизм хронометража (performance.now, целые сотые) |
| js/distances.js | схемы дистанций (разгон + круги) |
| js/norms.js | нормативы ЕВСК, перенесены из «Разрядного калькулятора» |
| js/comparison.js | ввод графика (4 поля), отклонения, итоги сравнения |
| js/app.js | управление замером, режимы, таблица, сброс |
| js/storage.js | IndexedDB `skto-smart-stopwatch-db` (журналы + активный замер) |
| js/journal.js | журналы, копирование, просмотр для скриншота, JSON-бэкап, навигация |
| js/recovery.js | восстановление после сворачивания/закрытия, правило 10 минут |
| js/feedback.js | звуки, вибрация, Wake Lock, тема, настройки |
| js/templates.js | шаблоны сравнения: хранение (IndexedDB meta, ключ `cmpTemplates`) и интерфейс |
| js/help.js | справка «i», ссылки и информация о СКТО |
| js/update.js, sw.js | офлайн-кеш и безопасное обновление |
| manifest.json, icons/ | установка PWA, официальные иконки |

## Публикация на GitHub Pages
1. На github.com: **New repository** (например `skto-stopwatch`), Public, без README.
2. **Add file → Upload files**: перетащите **содержимое** распакованной папки (index.html, manifest.json, sw.js, css, js, icons — не саму папку-обёртку). **Commit changes**.
3. **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: main, / (root) → Save**.
4. Через 1–2 минуты приложение откроется по адресу `https://<аккаунт>.github.io/skto-stopwatch/`.

## Установка
- **iPhone (Safari):** открыть адрес → «Поделиться» → «На экран Домой».
- **Android (Chrome):** меню ⋮ → «Установить приложение» / «Добавить на главный экран».

## Обновление без потери данных
1. Замените изменённые файлы в репозитории (Upload files → перезаписать).
2. **Обязательно** измените номер в `sw.js`: `const CACHE="skto-stopwatch-v1.0.1"` (любое новое значение).
3. Пользователи увидят баннер «Доступно обновление» после завершения замера (во время замера или паузы он не появляется). Журналы в IndexedDB обновление не затрагивает.

## Обновление нормативов
Нормативы лежат только в `js/norms.js` (блок `RAW`: 18 значений на дисциплину — МСМК м/ж, МС м/ж, … III юн. м/ж; «-» нет нормы; «?» значение не подтверждено и не используется). Измените значения, обновите `NORMS_VERSION`, поднимите версию кеша в `sw.js`. Старые записи журнала хранят свои разряды и не меняются.

## Шаблоны сравнения
Хранятся в `skto-smart-stopwatch-db` → хранилище `meta`, ключ `cmpTemplates` (версия БД и структура `records` не менялись). Записи журнала содержат собственную копию графика (`cmp.ref`), поэтому правка и удаление шаблонов их не затрагивают. Резервная копия JSON теперь содержит поле `templates`; старые копии без него импортируются как раньше.
